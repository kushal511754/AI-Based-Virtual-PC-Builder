                           THREE NEW API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

1️⃣  GET GAME REQUIREMENTS
    POST /api/ai/game-requirements
    
    Input:  {"game_name": "BGMI"}
    Output: {
      "game_name": "BGMI",
      "platforms": ["Mobile", "PC (Emulator)"],
      "minimum": {cpu_cores, gpu_vram, ram_gb, storage_gb},
      "recommended": {...},
      "high_end": {...}
    }

2️⃣  GET BUILD RECOMMENDATION
    POST /api/ai/game-build-recommendation
    
    Input:  {
      "game_name": "BGMI",
      "budget": 80000,
      "domain": "gaming"
    }
    Output: {
      "game_requirements": {...},
      "build_recommendation": {
        "total_estimated_inr": 65500,
        "approximate_component_costs": {
          "cpu_inr": 15000,
          "gpu_inr": 25000,
          ...
        }
      }
    }

3️⃣  VALIDATE PC FOR GAME
    POST /api/ai/validate-pc-for-game
    
    Input:  {
      "game_name": "Cyberpunk 2077",
      "pc_specs": {
        "cpu_name": "Intel i7",
        "gpu_name": "RTX 4070",
        "ram_gb": 32
      }
    }
    Output: {
      "can_run": true,
      "performance_level": "Ultra 1440p",
      "expected_fps_1080p": "100-120 FPS",
      "compatibility_score": 95
    }

                              HOW IT WORKS (Flow)
═══════════════════════════════════════════════════════════════════════════════

User enters game name (e.g., "BGMI")
        ↓
  [OpenAI GPT Analysis]
        ↓
  Extracts requirements:
  • CPU cores needed
  • GPU VRAM needed
  • RAM needed
  • Storage needed
  • FPS expectations
        ↓
  [PCBuildAgent Integration]
        ↓
  Matches with Indian market components:
  • Fetches real prices from Amazon, MDC, Vedant, PrimeABGB
  • Selects best value components
  • Calculates ₹ INR costs
  • Adds 9% GST/shipping buffer
        ↓
  [Response to User]
        ↓
  Shows:
  ✅ Game requirements (specs needed)
  ✅ Component breakdown (with prices in ₹)
  ✅ Performance predictions (FPS at 1080p/1440p/4K)
  ✅ Retailer sources (where to buy)
  ✅ Compatibility analysis (if validating existing PC)
